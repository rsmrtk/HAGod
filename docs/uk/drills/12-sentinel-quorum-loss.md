# Drill 12: Втратити кворум Sentinel

**Мета.** Зрозуміти, чому Sentinel може бачити, що master впав, і все одно нічого не робити.

## Історія
Помилка при обслуговуванні зупиняє два з трьох sentinel'ів, а згодом відмовляє Redis master.

## Спершу передбачте (запишіть)
- Чи вцілілий sentinel зробить failover сам?
- Що він каже про master?

## Запуск
```sh
make drill-12
make verify-12
```

Тримайте `make watch` відкритим у другому терміналі.

## Спостерігайте: команди, які варто спробувати самому
```sh
redis-cli -h sentinel1 -p 26379 sentinel master mymaster      # flags: s_down (не o_down)
redis-cli -h sentinel1 -p 26379 sentinel ckquorum mymaster    # NOQUORUM ... недостатньо, щоб досягти більшості
docker logs sentinel1 2>&1 | tail
```

## Що ви маєте побачити
Один sentinel ставить master **`s_down`**, ніколи не `o_down`, і **failover не відбувається**, поки інші sentinel'и недоступні. `CKQUORUM` повідомляє `NOQUORUM 1 usable Sentinels`. Щойно sentinel'и повертаються, failover завершується за секунди, а загальний простій — це час, який ви витратили на їхнє виправлення.

## Зрозумійте
Два різні пороги: **quorum** (2) — скільки sentinel'ів мають погодитись, що master впав; але щоб справді зробити failover, один sentinel має бути **уповноважений більшістю всіх відомих sentinel'ів** (2 з 3). Коли лишився один sentinel, жодне недосяжне. Зниження quorum до 1 не допоможе: правило більшості все одно потребує 2.

## Виправлення
Поверніть sentinel'и; ніколи не працюйте в проді з менше ніж 3 (на різних хостах). Моніторьте **кількість sentinel'ів**, а не лише Redis master.

2. Чому sentinel'и мають бути на окремих машинах одне від одного, а не лише від вузлів Redis?
3. На що б ви ставили alert?

---

### Відповіді (читайте після спроби)
1. Втратити 1 з 3. Із 2 sentinel'ів не можна втратити жодного (більшість — 2). Quorum 1 не змінює більшість, потрібну для авторизації failover.
2. Щоб відмова одного хоста прибирала щонайбільше одного sentinel; якщо sentinel'и ділять хост із вузлом Redis, втрата цього хоста прибирає і master, і вартового.
3. `SENTINEL CKQUORUM` не OK, менше ніж 3 відомих sentinel'и, sentinel із `s_down`.
